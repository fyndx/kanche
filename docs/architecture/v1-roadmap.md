# Kanche roadmap

This is a high-level public summary. Planned capabilities are unshipped and have
no committed release date. Detailed planning and delivery tracking are private.

## Available in this branch

- Operator-provisioned tenant identities and application enrollment.
- App-owned and hosted password login for provisioned, verified accounts.
- Online app-bound sessions, expiry, renewal, sign-out and operator revocation.
- TypeScript server SDK and Next.js integration.

See the [app-owned guide](../contracts/app-owned-integration.md),
[hosted guide](../contracts/hosted-integration.md), and
[verification limits](../verification/hosted-login.md).

## Planned

- Public signup, account verification delivery, and password recovery.
- Organization membership and application access management.
- Developer console and self-service onboarding.
- Deployment validation, recovery drills, and capacity testing.

## Future evaluation

External identity connections and additional hosting options remain proposals.
Passing repository checks does not establish production readiness or standards
interoperability.
